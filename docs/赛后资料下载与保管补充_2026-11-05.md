# 赛后资料下载与保管补充

2026-11-05，按用户确认调整[跨比赛账号与数据管理方案](跨比赛账号与数据管理方案.md) §9 及其中依赖网站归档存储的内容。网站与比赛服务不需要 Cloudflare R2。账号、会话、比赛、战报版本和清理记录仍由各自的 SQLite Durable Object 管理。

- 完赛后，正式参赛者和有权限的工作人员可在本场查看战报与保留期内的完整复盘。平台所有者或获本场授权的资料管理员可直接下载战报、完整复盘、裁判操作记录和加密备份。下载时按当前权限和保留期生成文件；战报可指定版本，裁判操作记录和加密备份需要近期验证身份。下载记录留在平台，下载文件由主办方自行保管。
- 网站没有另外的归档文件库、归档发布任务或历史归档包导入功能。在线历史来自比赛数据库。清理在线数据不影响已下载的文件；主办方按自己承诺的保留期限处理这些文件。
- 网站上的到期复盘清理仍检查完赛、战报、保留期限和申诉状态，保留七天等待期。执行时先在独立的平台数据库写清理记录，再裁剪本场信息。清理后仍可在保留期内查看战报，受限审计继续按原权限管理。单场恢复不会回退平台的清理记录，已清理的比赛不能通过旧检查点重新开放完整数据。
- 加密备份是由主办方保留的资料。运维向导仍使用本场的加密检查点和恢复材料处理允许的单场恢复；网站不会把下载文件重新上传为历史条目。

首次开站、领取账号和日常操作见[云端办赛快速上手](办赛快速上手.md)。

本轮本地验证：`npm run check` 通过，包含格式、ESLint、类型、前端构建及 Worker 模拟打包；打包绑定中没有 R2。平台与维护集成测试共 23 项通过，前端请求和运维协议单元测试共 10 项通过。用模拟资料在本地浏览器核对了战报查看、下载入口和资料管理页面。没有运行完整测试套件、真实时间赛程或高成本测试。该版本现已部署至云端 preview，部署编号和云端验证边界见[跨比赛实现说明](跨比赛账号与数据管理实现说明_2026-11-05.md#preview-部署与云端使用)。
