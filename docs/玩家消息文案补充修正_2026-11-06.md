# 玩家消息文案补充修正

本文记录2026-11-06用户授权的玩家消息用语调整，适用于官网事件、QQ群公告、QQ私聊、玩家复制模板、四维观战及相关操作提示。文案以《黑暗森林：观察者效应》完整策划案§3.2、§4.2、§5.1、§7.4、§8.2—§8.3的模板为基础。

## 模板与身份

保留模板的叙事口吻和行动指引，去掉示例中包围文明、坐标、次数等填充值的半角方括号。文明身份使用现有 `Engine.identity` 的结果，例如 `C07（哈基米）`。消息标题保留 `【】`，QQ复制正文带上标题，官网单独展示标题。

母星登记、重生、广播、歌者、光粒、母星毁灭、技术爆炸和维度跃迁优先沿用原模板。首航发码保留用户手改的“做好准备”文案，正式开赛保留“全部文明统一出航，比赛计时开始”。裁判设置公告保留用户手改的简短表述。

## 玩家用语

原模板中的“失配”“禁攻”等用词按用户要求停用。玩家消息直接说明“本次提交的手环颜色有误”“累计错误”“禁止目击攻击”“恢复攻击时间”和再次提交错误颜色的处罚。“目击码”“退役码”等表达改为手环颜色或已失效的手环配置，集合地点统一称为“中控室”。

规则书未提供原句的消息，直接写明发生的事与下一步行动。删除重复提醒、预先反驳、无关解释及玩家无需了解的工程术语。处罚时长、概率、观战等待与重生截止根据本场实际设置填写。

操作提示使用“操作未提交”“请等待结果”“上次更新”等具体表述。手环状态使用“使用中”“已失效”“暂无手环配置”。取消操作等内部结果标记不向玩家展示，六位位置口令继续正常显示。

## 官网与QQ

官网本人消息采用本人语气。四维观战展示相关文明、事件经过或注明收件人的通知，击毁者身份沿用现有查看范围。QQ正文保留适合转交实际收件人的称呼。自然事件和裁判触发的同类事件使用相同的玩家文案。

本次调整生成消息、模板及展示文字，不修改赛事规则、消息公开范围或已存储的历史记录。裁判自行填写的公告与裁决原因保留原文。
