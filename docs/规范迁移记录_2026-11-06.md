## 本轮改动

1. 保留 Prettier 和 ESLint，增加 `eslint-config-prettier`、`eslint-plugin-react-hooks` 并锁定版本；JS/TS 使用 80 目标宽度，其余文件保持原有格式选择。
2. 全库执行格式和机械规则修复，包括控制流大括号、单变量声明、对象接口、数组语法和类型导入；前后端依赖隔离继续强制执行。
3. 38 个 TS/TSX/MJS 手写文件及 1 个对应声明文件改为 snake_case；同步 import、npm 脚本和文档引用。框架入口、包名、HTTP 路径、SQL 字段和 JSON 键保留原有契约。
4. 存储查询泛型改为逐字段检查 SQL 值，支持具名 interface。SQL 执行使用 `T & Record<string, SqlStorageValue>`，不增加运行时断言。平台 SQL 行类型去掉只存在于前端投影中的 `membership`，实际查询与响应不变。
5. 从 `apps/web/src/ui.tsx` 提取 `notchPath`、`CutOutline`、`Frame` 和 `Button` 到 `components/cut_frame.tsx`。保留 UI 原有再导出接口；DOM 结构、CSS 类、默认参数、事件接口与 ResizeObserver 生命周期不变。
6. 已清理范围直接启用类型感知检查；全库剩余报告逐条登记并通过 CI 基线约束，禁止新增。新增规范工具回归测试验证规则确实生效及基线不会漏掉替换或重复问题。
7. 检查顺序调整为先生成 Wrangler 类型，再执行 lint 与 TypeScript；保留独立 `typecheck` 命令。

两份受保护核心文档没有修改。本轮没有调整游戏规则、权限、时钟、结算、数据 Schema 或对外序列化字段。
