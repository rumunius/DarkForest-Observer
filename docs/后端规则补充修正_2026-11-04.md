# 后端规则补充修正（2026-11-04）

本补充记录用户在后端规划阶段明确确认的两项执行口径，适用于后端实现、接口、裁判后台与验收。两份核心文档保持原文，其余规则继续按原方案及已有补充执行。

## 1. 单场目击超过120次的处理

原技术方案§5.7规定“单场超过120次需总裁判复核”，未明确复核前是否停止受理。用户确认：**继续受理，只向裁判告警。**

- 保留每账号至少4秒间隔、滚动60秒最多10次，以及阶段、个人禁攻、临时效果等既有门禁。
- 单场目击累计超过120次时产生裁判告警，保留计数和可追踪的复核记录。
- 不因该阈值自动关闭目击资格，不要求总裁判点击放行后才能继续，不额外累计失配或延长禁攻。
- 同一请求ID重试不算新的目击受理；不得因轮询或网络重试重复制造告警。具体告警去重与复核状态属于工程实现，不改变受理口径。

验收应包含第120次、第121次及之后的合法新请求：满足其他规则时继续受理，裁判能够看到超阈值告警；其他限速和资格门禁仍正常生效。

## 2. 技术爆炸的候选文明

原策划案§4.6及技术方案§9.6将候选写为“母星仍存且尚未升级”，没有明确排除已主动退赛、永久淘汰的文明。用户确认：**排除已永久淘汰和退出正式名单者。**

每次技术爆炸到期时，在同一场次的最新权威状态中筛选：

1. 属于本场正式参赛名单，尚未退出正式名单；
2. 尚未永久淘汰；
3. 母星仍存活；
4. 尚未通过技术爆炸升级。

从符合全部条件的文明中均匀抽取一名。仍有合法重生资格的返航、准备重生或已领取待激活配置者可以参与；中奖后仍需正常出航并满足第一阶段权限才能发射光粒。不得把候选错误收窄为只有active飞船。

候选为空时按原规则记录事件完成，不产生升级者，不补抽新的事件时刻。技术爆炸次数公式、秘密排程、单文明至多升级一次及65分钟行动截止保持原规则。

验收需覆盖正常出航、合法返航、重生准备、已领待激活码、永久淘汰、退出正式名单、母星已毁、已升级及无候选场景。
