# 云端办赛快速上手

打开[云端赛事中心](https://dev.darkforest-pages-dev.pages.dev/matches)。玩家、裁判和日常办赛人员只需要浏览器，不需要在电脑上启动网站。

## 第一次领账号

1. 打开主办方单独发给你的邀请链接，点 **领取并生成长期口令**，把新口令存好。邀请只用一次，之后都用长期口令登录。
2. 回到 **我的比赛**，选择 **玩家** 或 **工作人员** 登录。已有长期口令的人不需要再领一次。
3. 找到这场活动，点 **接受邀请**。玩家再点 **确认本场文明**；裁判接受后等主办方安排岗位。

## 主办方怎么开一场试玩

1. 用工作人员账号登录。到 **账号池** 填姓名、选账号类别，点 **创建并交付邀请**。把领取链接单独发给本人。
2. 点 **新建比赛**，选择 **试玩**，填写名称、说明和资料保留期限，确认创建。打开 **管理比赛**，把玩家和裁判邀请到本场。
3. 等人员接受邀请后，安排三位不同的裁判岗位，并确认至少两名玩家已确认本场文明。点 **发布准备入口**，再由总裁判在工作台选正式名单和安排开赛。看到“已受理”时，到 **管理待办** 确认操作已完成。
4. 完赛后，从 **历史与数据** 选择比赛，点 **查看与下载赛后资料**。战报可以按版本下载；需要留存的完整复盘和加密备份请在保留期内下载。文件由主办方保管，裁判操作记录和加密备份只交给获准查看的人。

## 空站还没有第一位所有者

这一步由网站维护人员完成。在项目目录运行 `npm run admin:wizard`，用方向键选择 `dev.darkforest-pages-dev.pages.dev.environment.json`，按 Enter。核对向导显示的网站地址后，选 **首次建立网站所有者**，输入显示名称并按提示确认。

这个环境文件已为本机配置，里面保存向导连接云端用的平台维护凭据。它和网站长期口令分开。换电脑时，由维护人员按[运维说明](../README.md#云端运维向导)配置环境；不要把维护凭据发给玩家。

向导会给出领取文件的位置。复制文件里 `invitation` 的值，到[云端领取页](https://dev.darkforest-pages-dev.pages.dev/claim)生成长期口令。用 **工作人员** 登录，到 **账号与安全** 按提示设置并验证第二因素，再开始发账号和办比赛。

同一个站点只需建立一次所有者。平时在网站办赛；接入已经暂停的旧比赛或处理恢复时，再打开向导，按提示先保存检查点。中途断开时，选 **继续未完成的恢复或接入操作**，沿用原操作继续。
