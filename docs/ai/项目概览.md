## 项目与角色

前端按当前状态渐进披露：不适用的操作整体隐藏，首航与重生只呈现当前步骤，规则及历史按需查看。具体条件见前端功能规划§3与设计系统§6.4。

《黑暗森林：观察者效应》是校园实景生存淘汰游戏，标准规模为24名独立文明、3名裁判。玩家本人代表飞船，拥有一颗秘密母星；现场步行观察他人两臂手环分组，通过官网提交目击攻击。母星情报、广播、歌者和光粒构成信息博弈。来源：策划案 §1、§4。

玩家完成现场观察、佩戴、网页操作和QQ材料提交；服务器裁定线上状态和规则；裁判负责照片审核、QQ通知、现场安全、终局位置核验和纠错。永久淘汰者成为四维观察者，可线下提案，由裁判决定是否执行。来源：策划案 §7、§10、§15；技术方案 §1.2。

## 比赛主线

| 节点             | 必须理解的含义                                                                         |
| ---------------- | -------------------------------------------------------------------------------------- |
| 赛前、T0、T1     | 母星审核与准备；T0发行首航码、佩戴确认；T1统一激活飞船并开始比赛。发码不等于已可攻防。 |
| 有效时间0—65分钟 | 黑暗森林：目击、符合条件的重生、正式广播及宇宙事件。                                   |
| 65—90分钟        | 宇宙末日：母星统一毁灭，已出航者最后一命，未出航者淘汰。                               |
| 90—98分钟        | 转场：暂停目击，使用QQ群位置共享，步行进入终局区。                                     |
| 98分钟           | 截止资格并自动暂停有效时钟；裁判核验，总裁判确认后恢复。不是到点自动开放攻击。         |
| 98—120分钟       | 最后狩猎；通常保留22分钟有效时长，亦可能触发提前完赛。                                 |

完整结算后存活文明不超过1个时可以提前完赛；仍有重生资格者也属于存活文明。终局核验按批次结算，不能逐个淘汰时提前截断。来源：策划案 §2、§5、§6；技术方案 §11。

## 容易混淆的概念

- **手环码与母星坐标不同。** 手环码由七色的两组颜色集合构成，仅允许 `2+1 / 2+2 / 3+1`，同臂无序、两臂交换等价；350枚码按场永久不复用。母星是六位十进制字符串，保留前导零。来源：策划案 §1.2、§3；技术方案 §4.1、§5。
- **飞船被击毁不一定永久淘汰。** 第一阶段正常被目击击毁、母星尚存者可在15分钟期限内且早于65分钟完成重生；返航、准备和换码共用期限。母星毁灭时是否正在出航会影响结果。错误攻击导致的直接出局不可重生。来源：策划案 §4.1、§4.2、§4.7；技术方案 §8.4、§9.8。
- **禁攻不等于免战或全场暂停。** 失配次数整场累计；历史退役码、自码、重试等有例外，必须核对完整分类，不能把所有未击毁都记为失配。来源：策划案 §4.1；技术方案 §5.5、§5.6、§7。
- **两套时钟不能混用。** 比赛阶段、重生和游戏事件使用暂停时冻结的有效比赛时钟；个人错误攻击禁攻、淘汰后180秒观战等待及UTC临时效果使用真实UTC。来源：技术方案 §2.4。
- **生存优先，战绩按不同文明去重。** 同一目标重复击毁、母星毁灭不等于新增去重目击战绩；淘汰者还涉及生效时间与并列组。来源：策划案 §2.3、§7.2、§7.3；技术方案 §12。
- **观战不是裁判身份。** 永久淘汰满180秒后原账号可只读全局观战，禁止正式行动；不能向活人通报情报，也不能获得管理权限、密钥或未来随机安排。来源：策划案 §7.4—§7.7；技术方案 §3.4、§14.5、§15.5。

## 技术设计边界

设计链路为 Cloudflare Pages 前端 → Pages Functions 同域HTTP入口 → 单场唯一的 SQLite-backed Durable Object Worker。比赛状态集中在该对象的SQLite中；最终身份、角色和赛事授权在服务端完成，不能依赖隐藏按钮或客户端倒计时。来源：技术方案 §1.2、§2.1、§6.1。

权威操作先经过到期事件屏障，再根据最新状态结算；原子性、幂等、发码永久唯一和审计是跨玩法约束。Alarms与入口补结算共同驱动事件，不依赖浏览器持续在线。来源：技术方案 §2.5、§4.4、§6、§16。

QQ承担人工通知、照片及终局位置共享；官网记录裁判裁决，不自动替代现场执裁，也不把QQ位置轨迹存进赛事系统。来源：策划案 §15；技术方案 §13、§17。
