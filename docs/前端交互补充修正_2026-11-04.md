# 前端交互补充修正（2026-11-04）

依据用户本次明确要求，本补充覆盖《网站前端设计系统》§6.4、§8及《网站前端页面与功能规划》§3、§4.5、§4.7、§7中对应的旧交互约定。核心策划案和技术方案原文保持不变。

1. 比赛规则目录使用 `#rules-N` 定位具体小节；兼容先前的 `#rule-N` 地址。页内锚点、直接打开和历史导航均优先章节定位，不被页面滚动恢复覆盖。开发工具栏是否存在不应影响定位。
2. 阶段标签统一显示“当前阶段：”。比赛摘要下方增加细赛程条，整条表示120分钟，按65、90、98、120分钟划分，显示当前阶段、已用与剩余有效时间。暂停和98分钟核验冻结有效进度；提前完赛显示已结束，不伪装已进行120分钟。
3. 行动页始终显示广播、光粒额度行，包括尚未获得、资源耗尽及不适用状态。没有资格时显示“不可用”代替箭头，整行不可点击，不开放输入与提交；有资格时才链接至表单。“我的”始终显示广播剩余次数及光粒额度。接口授权和玩法阶段限制不变。
4. 进入目击页面默认选中“一侧手臂”；清空或一次攻击完成后恢复该输入侧。向已满三条的手臂加入颜色时，若总量仍允许，自动切换到另一侧并加入；另一侧同理。总量四条上限、颜色唯一和最终合法形状不变，已达四条时拒绝新增并保留原草稿。
5. 目击页移除“显示颜色名称”开关，仅通过“我的 → 账号与显示偏好”调整，目击页遵循该全局偏好。移除“交换两侧”及首航的交换示意按钮，仍可手动跨臂移动。
6. “确认攻击”先打开二次确认弹窗，呈现完整配置和当前错误攻击后果；默认焦点在“返回检查”。只有点击“确认提交攻击”才发起网络操作。取消、Escape不提交并保留草稿；提交后仍沿用幂等和结果恢复机制。
7. 手臂板块选中与键盘焦点复用同一条闭合切角描边；焦点用浅蓝色描边区分，不额外叠加外圈，避免双重轮廓。

以上是前端交互调整，不改变权威比赛规则、错误处罚、服务器允许动作或服务端结算。
