# 《黑暗森林：观察者效应》完整策划案

> 文档状态：赛事执行依据｜120分钟三阶段生存淘汰赛  
> 使用对象：主办方、裁判、玩家宣讲负责人  
> 适用规模：24名独立文明、3名裁判；20—30人可按场地调整  
> 配套文档：黑暗森林_技术方案.md  

## 1. 活动定位

《黑暗森林：观察者效应》是一场以24个独立文明为基准的校园实景科幻生存游戏。每名玩家代表一个文明，拥有一颗秘密母星，本人是一艘在校园内步行行动的飞船。玩家使用**七色普通魔术贴手环**标识每个航次的目击码。玩家通过观察他人两臂佩戴的手环颜色与分组，在官网提交目击码，命中即击毁飞船并获得其母星情报。

目击码**只取两臂佩戴的手环颜色集合与分组**，与外貌、手环粗细、图案朝向及同臂穿戴顺序无关。左右臂整体交换不改变码的语义。每名玩家领取同一套七条手环，正常出航时只佩戴3或4条，其余放在口袋内。

母星尚存时，被击毁飞船立即摘下所有比赛手环，必须在15分钟内返航、提交水印照片、离巢50米、领取新手环排列并确认出航；母星毁灭后，已出航飞船只剩最后一命。玩家可以进行真假情报交易、官网坐标广播、引来歌者，以及利用秘密技术爆炸获得的光粒打击母星。

排名规则：**比赛结束时仍存活者优先；幸存者按成功目击击毁过的不同文明数排序，同数并列。** 正赛有效时长120分钟；65:00母星统一毁灭，90:00开始转场，98:00终局资格截止并进入裁判核验暂停。

永久淘汰的玩家成为「四维观察者」，摘环后尽快返回中控室，与裁判和其他观察者共同观看宇宙、聊天和参与桌游。永久淘汰满3分钟，玩家原账号开放只读全局观战。观察者可以在中控室商议趣味干涉并向裁判提案；由裁判通过管理指令控制台或线下方式决定和实施。活人继续进行生存竞技，死者遵守不向活人通风报信的君子协定。

### 1.1 核心体验

1. **低调目击：** 现场辨认目标两臂手环的颜色与分组，在官网提交目击码；本人亲眼观察是合法目击的依据。
2. **一船一命：** 每个航次对应一枚本场未使用过的手环码；击毁后码永久退役，下一次合法出航获得全新码。
3. **秘密母星：** 母星尚存才有正常重生机会；已出航飞船在母星毁灭后进入最后一命。
4. **情报博弈：** 六位母星坐标可交易、传播、欺骗或正式广播，广播真实母星会使被广播者获得发报文明的母星坐标。
5. **宇宙事件：** 歌者对已正式广播坐标独立清理；第一阶段按参赛人数动态安排秘密技术爆炸，可能带来一枚可即时发射的光粒。
6. **末日狩猎：** 65:00全体母星毁灭；90:00QQ群位置共享与转场；98:00比赛时钟暂停，裁判核对终局资格并人工淘汰，核验完成后开启22分钟最后狩猎。
7. **维度跃迁：** 永久淘汰者返回中控室，3分钟后获得只读全局观战权限，在「四维宇宙」中继续交流、观战与娱乐。
8. **高维干涉：** 观察者可线下讨论并向裁判提案；裁判借助赛事通用管理指令或现场活动，酌情实施轻度宇宙现象。

### 1.2 七色手环与350码容量

所有玩家领到七种颜色各一条，采购名以当前供货商页面为准。结合本次供货页面的视觉观感，推荐使用以下七色：

| 固定编号 | 供应商颜色名 | 选择理由与提醒 |
|---|---|---|
| BK | 黑色 | 最深端点，适合作为深色基准 |
| WH | 白色 | 最亮中性色；与灰色成对重点实测 |
| GY | 灰色 | 中性灰，和白色形成稳定明度层级 |
| YL | 黄色 | 高亮暖色，远距离可见性好 |
| OR | 桔色 | 与黄色同属暖色，但饱和度和色相更醒目；需重点实测 |
| SB | 天蓝色 | 明亮冷色，与黑、灰、黄、桔区分直观 |
| PU | 紫色 | 冷色端点，与天蓝形成清晰差异 |

当前供货商还提供棕色、浅绿色、粉红色、红色、蓝色等备选项；本方案优先采用**黑、白、灰、黄、桔、天蓝、紫**这七色，以便在肉眼快速辨认时保持较高区分度。正式采购前仍应先买少量样品，在日光、树荫和夜间照明环境下进行实物试认。

**唯一合法的佩戴类型：** `2+1`、`2+2`、`3+1`。例如“黑＋桔｜白”是`2+1`；“黄＋天蓝｜黑＋灰”是`2+2`；“白＋灰＋紫｜黄”是`3+1`。一个颜色在一个航次中最多出现一次，同臂内不区分顺序，两臂交换等价。其余3或4条未佩戴手环留在口袋里，不参与该航次的码。禁止无环、单臂全部佩戴及其他类型出航。

| 两臂分组 | 7色码数 | 算式 |
|---|---:|---|
| `2+1` | 105 | `C(7,3) × 3` |
| `2+2` | 105 | `C(7,4) × 3` |
| `3+1` | 140 | `C(7,4) × 4` |
| **总计** | **350** | `105+105+140` |

24人首航占用24码，此后理论尚余**326枚可再发行码**，其中重生、设备异常退役后的替代码共用同一容量。**重生不设累计次数上限，所有已发行手环码永久占用本场码本。** 350枚全部发行后，系统向总裁判报告码源耗尽，裁判暂停比赛并向全场说明赛事异常及处置方案。

## 2. 全场流程

### 2.1 正式比赛前

| 示例时间 | 事项 |
|---|---|
| 14:30—14:50 | 签到、独立登录凭证、设置昵称；领取七色各一条的规格相同手环，测试QQ私聊 |
| 14:50—15:05 | 宣讲两臂分组码、颜色辨认、直接出局和冷却规则、比赛区域与终局地图、网站图形化输入、QQ共享位置、四维观察者与君子协定 |
| 15:05—15:15 | 玩家登记高德24小时六位母星口令并发送裁判QQ私聊与水印照片；裁判审核 |
| 15:15—15:24 | 离母星至少50米、核对七环完整且未佩戴比赛码、登录官网、点击「待发码就绪」 |
| 15:24—15:25 | 裁判锁定首航名单并公示T0倒计时 |
| **15:25（T0）** | 本人官网领取两臂颜色配置，在安全位置佩戴相应3—4条手环、其余收入衣袋，点击「穿戴就绪」 |
| 15:25—约15:28 | 全员按码佩戴，暂停全部正式攻防，裁判检查就绪人数及穿戴情况 |
| **约15:28（T1）** | 全体就绪后裁判启动约30秒统一倒计时；T1同时激活所有正式飞船，120分钟比赛开始 |

T0为首航码发行时刻，T1为比赛开始时刻。实际T1以全员就绪后裁判锁定的服务器时间为准，65/90/98/120分钟节点均相对于实际T1计算。T0之前不得提前领取首航码；T0至T1不得通过观察其他玩家提前收集编码，T1后必须重新现场观察才可攻击。

佩戴确认必须在安全位置进行，不得在道路转角、楼梯和车道边停留调整手环。玩家按网页配置佩戴手环即可。

### 2.3 冠军与名次

**生存资格优先于目击战绩。** 正赛在有效时钟120:00结束，或在正式参赛文明仅剩一名时自动提前结束。结束时仍存活的所有文明排在已淘汰者之前。幸存者按**成功目击击毁过的不同文明数量**从多到少排列；同数并列，最高数者获得冠军。

- 永久淘汰结算后仅余一名文明：系统立即完赛，该文明为唯一冠军。第一阶段返航、换码中的文明仍有重生资格，属于存活文明。
- 多名文明存活：去重目击击毁数最高者为冠军；最高数有多人相同则并列冠军。
- 对同一目标的反复击毁、歌者清理母星、光粒攻击母星，不增加去重目击击毁数。
- 已永久淘汰者按淘汰生效时刻从晚到早排序；同一批赛事事件淘汰者以及98:00终局资格淘汰组并列。
- 存活者中的全部名次确定后，已淘汰者从`幸存人数+1`名起排序；同分并列名次按竞赛排名方式跳号。

若一次结算后所有文明均已永久淘汰，比赛立即结束，不产生存活冠军；已淘汰者按生效时刻与并列组排序。自动完赛在单笔攻击、超时或全域事件完整结算后触发；98:00的人工终局资格名单在总裁判完成核验时统一结算完赛条件。比赛没有加时赛和额外决胜环节。

玩家在**本人网页**实时查看自己的去重目击击毁数；比赛进行期间不发布全场击毁排行榜；比赛结束后，正式战报公开最终战绩与名次。

## 3. 身份、昵称与母星登记

### 3.1 文明编号与不可修改的昵称

开赛前为玩家分配`C01`、`C02`等文明编号。第一次登录时设置文明昵称，确认登记后锁定；裁判在报到时可以更正不合规昵称并留档。昵称建议2—8个汉字或等长字符，须唯一、适合公开交流。

**文明编号只用于官网、QQ群、裁判通知和最终战报，不出现在手环上，也不参与目击码。** 网页和公告中的文明身份格式为`C07·哈基米`。QQ群名片使用同一格式，供外交联系和第90分钟的位置共享核验。

### 3.2 母星坐标与登记

每位玩家选定允许活动区域内安全、公开可步行抵达的室外位置作为母星。在高德地图为该地点生成**24小时有效的六位数字位置口令**。母星判定按六位字符串完全相等；`001234`的前导零保留。网站将高德位置口令作为字符串保存、比对和广播，实际地点由裁判在高德地图人工核验。不同文明的已审核母星口令和真实地点都必须互不相同。

登记步骤：

1. 玩家在母星现场取得高德位置口令并拍摄带当前时间水印的照片。
2. 在官网登录页填写该六位口令，点击「提交母星待审核记录」，系统保存口令和提交版本。
3. 点击「复制母星登记消息」，发送到指定裁判QQ私聊，并附上现场时间水印照片。QQ消息中的口令及版本号应与本人网页一致。
4. 裁判在后台查看待审核的玩家编号、口令、提交版本，核对高德位置、现场照片与活动区要求，点击「审核通过」或「驳回」。审核通过后官网显示「母星已登记」。
5. 玩家离母星至少50米，进入首航准备流程。

示例登记消息：

```text
【母星登记】
文明[C07·哈基米]请求在[001234]登记母星（提交版本：[2]），以下是我的母星现场时间水印照片：
```

### 3.3 七色手环与目击码

每名玩家分发七种指定颜色各一条，全部为同款同宽度的普通魔术贴手环，不加入粗细、材质、图案朝向等编码维度。合法出航时佩戴数只能是3或4，且两侧分别为`2+1`、`2+2`或`3+1`。一臂内手环滑动、互换上下顺序不改变目击码；整组左右对调亦不改变。严禁同色两条、同色跨臂重复、单臂全部佩戴或超出这三种类型的配置。

玩家领取配置后，只需按网页图示把对应手环戴到两侧手腕或前臂，未使用的其余手环放入口袋；不需要玩家记忆编号、手动计算码值或保持手环固定顺序。普通出航者必须让双方的比赛手环在袖口之外可观察，不得故意以长袖、物品、背包或手掌遮挡；允许自然摆臂和正常走位。

**正常出航：** 两臂必须合规地佩戴配置，装备以服务器当前生效航次为准。

**被击毁、返航、准备、直接出局及永久淘汰：** 在安全位置立即摘下**全部比赛手环**并收入口袋；不允许只摘下一条伪装成无效码。此时不能发动或遭到目击攻击，按服务器状态处理。换码时维持摘环状态，调整好新的完整配置后点击「完成出航」，才恢复出航资格。第90—98分钟暂停攻击时，仍存活出航者继续佩戴当前配置。

所有已发行码在同一场比赛中永久唯一；码退役后永不复用。不同合法码可能仅有少量颜色差异，遇到颜色看错仍可能造成未命中或误中，玩家必须谨慎观察。

## 4. 第一阶段：黑暗森林（00:00—65:00）

### 4.1 现场目击、攻击失败与直接出局

仅正常出航且目击开放的玩家，可以在亲眼观察另一艘正常出航飞船**两臂手环完整颜色分组**后，通过官网选取「一侧手臂」与「另一侧手臂」的颜色集合并提交攻击。网页自动合并左右交换和同臂顺序，不接受目标文明编号、衣着外貌、拍照放大或其他辅助编码信息。首笔完成服务器事务的正确提交，击毁对应飞船并授予其已审核六位母星口令。对同一文明反复有效击毁仍只计一次去重目击战绩。

**攻击失配：** 服务器正式受理的合法目击码若未命中其他现役飞船，按码本记录判定。命中本场已退役的历史手环码属于无效目击，**不累计失配**；提交本人本场码、真实并发抢先击毁等情况也不累计失配。未发行码和他人尚未激活的码计为失配，执行以下累计处罚：

| 本场累计失配次数 | 本次结算 |
|---|---|
| 第1次 | 禁止目击攻击5分钟 |
| 第2次 | 50%概率永久淘汰；50%概率禁止目击攻击15分钟 |
| 第3次 | 永久淘汰 |

**直接出局**表示该文明永久淘汰、无论母星原先是否存活均不可再重生；若母星尚存则同步将其判为毁灭。此结果不是其他玩家的目击击毁，不增加任何人的去重战绩。直接出局玩家立即摘掉全部比赛手环、停止攻防和实时情报传递。幸存于失配抽签的玩家依然保持正常出航、仍可被别人击毁；禁攻只限制目击提交，不构成免战，不妨碍其他仍合法的广播、光粒与外交。

失配次数整场累计，不随成功击毁、重生或时间经过清零。以下请求不计失配：本场已退役旧码、自己的本场码、格式不合规或未正式受理的请求、相同`request_id`网络重试、禁攻中和比赛暂停时被拒请求、服务器可证实的同一目标并发抢先击毁。所有目击提交受账号级节流约束。

**攻击确认：** 网页在提交前显示两侧颜色排列、当前累计失配对应的处罚和最终确认键。点击后由服务器结算。攻击成功展示目标的文明编号、昵称及母星情报；未命中统一提示「本次目击未产生击毁」，并展示本人累计失配次数与适用的禁攻截止时间。

命中目标的码立即退役。系统向目标提供返航期限或永久淘汰提示，裁判优先通过QQ发送失联通知。仍禁止传播当前有效手环码、远程猜码、互刷战绩、偷拍与用照片录像放大读码；目击必须发生于开赛后本人真实现场。

### 4.2 自助重生与15分钟总时限

第一阶段母星尚存且**被其他玩家正常目击击毁**的飞船立即进入`returning`，从服务器击毁游戏时刻起计算15分钟重生期限；65:00为更早硬截止。**不限制玩家成功重生的累计次数。** 全场暂停时重生计时冻结。因错误攻击触发「直接出局」的玩家不得重生。

1. **摘下全部手环。** 玩家收到飞船失联通知后，在安全位置摘下全部比赛手环，停止目击攻防，步行返回母星。
2. **返航拍照。** 在母星拍摄当前时间水印照片，使用官网复制本次重生消息并向裁判QQ私聊发送文字及照片，再在官网确认已发送。
3. **离巢。** 继续保持全部手环未佩戴状态，正常步行离母星至少50米，再在官网确认离巢并领取本场全新的两臂颜色配置。
4. **换码佩戴。** 在安全位置把3或4条指定颜色手环按图示戴在两臂，其余收入衣袋，核对当前配置。
5. **确认出航。** 点击「完成出航」并在官网看到成功后，飞船在服务器该时刻恢复攻防资格。

```text
【重生】
文明[C07·哈基米]已返回母星，请求重生，以下是我的母星现场时间水印照片：
```

每次重生都需要发送照片，裁判可事后核验，标准流程不必逐次等待裁判批准。`returning / preparing / issued`共用一次15分钟期限；未完成出航到期即永久淘汰。重生期间母星若被光粒或歌者摧毁，也直接永久淘汰。第65分钟到来时仍未正常出航者同样淘汰。

活动区必须确保从最远合法位置正常步行返航、拍照、离巢50米、佩戴手环和确认出航能在15分钟内完成。全部步行，不得奔跑。历史旧码和异常退役码永不复用；新的排列必须由官网发行。

### 4.3 民间广播、交易与假情报

玩家可在面对面交谈、私人QQ群、官方比赛QQ群及QQ私聊中自由交换、出售、公布或编造六位坐标口令。私下传播真实坐标、有效空地口令，以及`000000`等随意编造的口令，均属于合法的情报行为。

这种**民间广播**只产生玩家之间的信息传播效果，不消耗官网正式广播额度，也不会使对应坐标自动接受歌者巡猎。

高德口令能否解析到地点，与该口令是否对应本场已登记母星属于不同的判定。官网正式广播和光粒都接受符合格式的六位数字字符串。

### 4.4 官网正式坐标广播

每个文明最多有**2次有效官网广播**。飞船必须处于正常出航且未永久淘汰状态；母星已经毁灭的最后一命飞船仍可使用剩余次数。

玩家在官网只输入**六位数字坐标**，例如`001234`，不需填写目标文明。官网受理任意符合`000000`—`999999`格式、**本场尚未被正式广播过**的口令。接受一次后立即消耗一次额度，并公开这组口令。

```text
【坐标广播】
文明[C07·哈基米]发送了一条坐标广播[001234]，该坐标已暴露给全宇宙。
```

正式广播后的效果：
1. 这组六位坐标在全场记录为**已正式广播**，获得独立的歌者巡猎资格。
2. 若该坐标与某文明开赛登记的母星口令一致，实际拥有者私下获得发报文明的真实母星口令及当前存亡状态；包括该母星已经毁灭的情形。
3. 其他玩家只看到发报文明与广播坐标，系统**不在广播公告中宣布该处是否真的存在母星**。
4. 官网展示发报者当前剩余广播次数。已被正式广播的坐标可以通过公开广播记录查到，不再重复消耗额度。

无论口令对应真实存活母星、已毁母星、有效空地还是未被高德解析的六位数字，**一次成功正式广播都消耗1次额度**。对已公开坐标的重复提交、格式不符、广播次数耗尽或身份无资格的提交由服务器拒绝，不扣额外次数。

官网广播只是宣告坐标，真正清理由歌者决定。被广播母星的文明身份可以通过外交猜测，直到母星实际遭到摧毁前，系统不会替其他人鉴定身份。

### 4.5 歌者：独立坐标清理

第一阶段每一条**成功官网广播的坐标**都会独立接受歌者清理检定。以各坐标广播被正式受理的比赛有效时刻为起点，**每经过完整60秒进行一次5%首次清理检定**；若抽中，到访有效时刻就是该60秒窗口的结束时刻。不足60秒的尾段不检定。

- 每个坐标最多被歌者清理一次。
- 首次清理时刻保密，由服务器在广播成功时按每满60秒一次的独立抽签计划生成；若到65:00前没有抽中，该坐标本阶段不会到访。
- 不同坐标的检定互相独立；可在同一分钟出现多次清理。
- 歌者在第65分钟宇宙末日开始时停止。
- 空坐标与真实母星坐标受到同一套抽签规则，**空坐标不会分摊真实母星的清理机会**。

清理到期时，服务器将该六位口令与**当时仍存活**的已登记母星口令精确匹配：

| 清理结果 | 游戏效果 |
|---|---|
| 匹配尚存母星 | 摧毁该母星；若飞船正常出航则变成最后一命，其余出航准备状态直接淘汰 |
| 没有匹配尚存母星 | 该坐标清理完成，无文明母星因此毁灭 |

QQ群公告公开清理口令。实际摧毁母星时同步公告被毁文明编号、昵称，并向目标私聊通知；未摧毁存活母星时仅公布清理口令和结果。

一颗已公开坐标若在歌者到访前已被光粒摧毁，其预定歌者清理仍按计划发生，届时结果为“未摧毁现存母星”。

### 4.6 技术爆炸与光粒

第一阶段的秘密技术爆炸次数由T1正式开赛的文明数量 `N` 决定，推荐取值为：

`M = min(max(1, round(N/3)), floor((N-1)/2))`

这意味着技术爆炸次数会随参赛人数增加而增加，同时始终控制在开赛文明总数的一半以下。典型示例为：5人局2次、12人局4次、24人局8次、36人局12次。

开赛前，服务器为第8—55分钟随机安排 `M` 个技术爆炸时刻，并尽量让它们在第一阶段内自然分散。每次到期时，从**母星尚存且尚未升级**的文明中等概率抽取一人，秘密升级为高级文明，获得**一枚舰载光粒**；当时正在返航的中奖者须正常出航后才能发射。若事件到期时没有符合条件的文明，则该次技术爆炸仅记录事件发生，不产生升级者。

高级文明正常出航且未永久淘汰时，可以在网页输入**任意六位数字坐标**并点击「发射光粒」。发射成功即消耗唯一一枚，立即结算：

| 坐标实际情况 | 光粒效果 |
|---|---|
| 对应尚存的已登记母星 | 立即摧毁该母星 |
| 未对应尚存母星 | 发射完成，无已登记母星被摧毁 |

发射前不鉴定目标真实性；发射后公开被清理的六位口令和命中结果。打中母星的QQ群公告包含**文明编号、昵称、母星口令**；空坐标命中公告说明“未摧毁现存母星”。发射者身份保密，只对有权限的裁判可见。

光粒发射不要求目标已经被正式广播；飞船失去自己的母星后，可继续使用尚存的舰载光粒。65:00宇宙末日时，尚未使用的光粒失效。

### 4.7 母星毁灭与最后一命

歌者或光粒摧毁母星时：

- 飞船为`active`（已出航）：保留当前有效目击码，成为**最后一命**。
- 飞船为`prelaunch/ready/returning/preparing/issued`：**立即永久淘汰**。
- 已是最后一命的飞船：仍可目击攻击，并在第一阶段使用剩余官网广播次数及已获得的光粒；再次被目击击毁即永久淘汰。

飞船广播自己的已毁母星口令或其他坐标也按同一规则处理。母星状态仅决定重生能力，正常出航的舰载引力波天线及光粒发射器继续有效。

终局区域从开赛起公开，第98分钟一次性锁定，此后边界按本方案执行。玩家可在整个终局区内自由行动；主办方现场确认，从全场最远合法地点正常步行，8分钟内可以入圈。

### 6.2 第90分钟：打开QQ比赛群位置共享，立即向终局区移动

比赛第90:00—98:00共**8分钟**，计入120分钟正式比赛时长。比赛有效时钟连续运行。

### 6.3 第98分钟：裁判核验与终局开战

比赛有效时间到达98:00，位置共享与入圈资格截止，服务器**自动暂停比赛有效时钟**，目击攻击继续关闭。裁判从90:00起在QQ群共享地图监看幸存文明，结合截止时的实际情况确定终局资格：

- **截至98:00仍未加入比赛群实时位置共享的玩家，永久淘汰。**
- **98:00时仍位于终局圈外的玩家，永久淘汰。**
- **按时共享且位于圈内的玩家，保留终局参赛资格。**

裁判在官网管理界面勾选不合格文明，注明「未按时共享」或「截止时未入圈」。总裁判核对名单并点击「完成核验」，系统在一次事务中执行这批**人工裁定的淘汰**，按98:00记为同一并列淘汰组，并结束本次核验暂停。若此时仍有两名及以上文明存活，服务器同时开放目击攻击，从有效时钟98:00起进行**完整22分钟**的最后狩猎；若仅余一名或无人存活，系统直接完赛。

QQ群承载实时位置共享，裁判在QQ内查看地图并结合现场巡查裁决；游戏官网保存文明编号、淘汰原因、裁判和操作时间。玩家按时开启群共享并进入终局区即可。核验期间网页向幸存者显示「终局资格确认中」。QQ共享地图整体故障时，比赛保持暂停，裁判在地图恢复后完成裁决。

### 6.4 第98—120分钟：公开位置的最后狩猎

开战后，幸存者持续共享位置，在终局圈内正常步行、观察、绕行、伏击或结盟。玩家仍须亲眼辨认敌方两臂当前手环颜色分组，才能在官网发动目击攻击。

**终局期间的离圈和共享中断由裁判现场裁决。** 裁判持续监看QQ群共享地图，发现玩家离开终局圈、关闭共享、使用虚拟定位或由他人代持手机时，结合现场情况在后台手动执行淘汰；服务器成功提交该指令的时刻即为淘汰生效时刻。定位误差由裁判参照合法步行区域判断。

永久淘汰者停止共享并遵守四维君子协定。比赛结束后裁判终止QQ群实时位置共享。

### 6.5 玩家速记

> **第90分钟：加入QQ群实时位置共享，步行入圈，暂停攻击。第98分钟：比赛计时暂停，裁判核对共享与入圈资格；核验完成后恢复计时并开始最后狩猎。**

树林步道、转角与广场共同构成最后的狩猎区域。地图位置用于判断方向，实际击毁仍依赖现场目击。

## 7. 永久淘汰、四维观察与排名

### 7.1 永久淘汰条件

| 事件 | 结果 |
|---|---|
| 第一阶段被其他文明合法目击击毁且母星尚存 | 摘掉全部手环、返航，启动15分钟重生总期限 |
| 错误攻击触发「直接出局」 | 无论母星原先是否存活，该文明永久淘汰，不允许重生 |
| 重生期限到时未完成新航次出航 | 永久淘汰 |
| 第一阶段母星被毁，飞船已经正常出航 | 当前手环码仍有效，变为最后一命 |
| 第一阶段母星被毁，飞船正在返航或准备出航 | 立即永久淘汰 |
| 第一阶段最后一命被有效目击击毁 | 永久淘汰 |
| 65:00全域末日、飞船尚未正常出航 | 永久淘汰 |
| 65:00以后正常飞船被合法目击击毁 | 永久淘汰 |
| 98:00未按时共享位置或未进入终局圈，以及终局期间离圈、停止共享 | 裁判依据QQ共享地图及现场情况手动永久淘汰 |
| 主动退赛或严重违规 | 根据裁判正式记录结算 |

赛前没有完成母星审核和待发码就绪者在锁定正式名册之前处理，不进入正式生存排名。

### 7.2 有效去重目击击毁数

每名玩家的去重目击击毁数，等于其在本场**成功通过现场目击攻击击毁过的不同目标文明数量**。每对“攻击者—被击毁文明”至多累计1次。对同一目标的后续有效击毁仍能取得当次目击效果，但不增加去重战绩。

无效攻击、撤销的违规攻击、广播、光粒、歌者及其他系统原因造成的毁灭，均不计入此数。**该数在玩家个人网页实时显示**；比赛中没有全场去重击毁数排行榜或定时榜单公告。

### 7.3 排名与冠军

1. **生存优先：** 正赛结束时仍存活的全部文明排在已永久淘汰文明之前，结束条件包括有效时间120:00与存活人数不超过1个时的自动完赛。
2. **幸存者排序：** 幸存者按有效去重目击击毁数从高到低排列；数值相同者并列，最高名次者获冠军，可能出现并列冠军。
3. **淘汰者排序：** 所有已永久淘汰文明按淘汰生效时刻从晚到早排列；同一全域事件或同一98:00终局资格裁定批次并列。
4. **名次跳号：** 幸存人数决定淘汰者起始名次。例如2名幸存者的战绩为5、2，他们分别为第1名、第2名；下一名淘汰者为第3名。若3名幸存者战绩为5、5、2，他们分别为并列第1名、第3名；下一名淘汰者为第4名。

任一完整淘汰结算后，场内未永久淘汰文明仅余一名，系统即刻完赛，该文明获得唯一冠军；若已无存活文明，系统即刻完赛且本场无存活冠军。98:00裁判资格核验作为同一批次完成后统一检查存活人数。

终局同分并列，K/D、重复击毁总次数、广播次数或技术爆炸中奖次数不参与排序，也不安排加时对抗。

### 7.4 永久淘汰与维度跃迁

文明永久淘汰后，玩家转为「四维观察者」。这是参与活动的持续身份，不改变永久淘汰的时间、正式战绩和排名。第一阶段正常击毁后仍具重生资格的玩家继续执行15分钟返航流程，只有永久淘汰才触发维度跃迁。

1. **立即摘环。** 玩家在安全位置摘下全部比赛手环，停止目击攻防、侦察及对现存文明的外交与情报传递。
2. **返回中控室。** 按正常步行速度尽快返回赛前公布的中控室，与裁判及先前淘汰的玩家集合。原网页显示集合地点、本人淘汰时刻和观战解锁倒计时。
3. **解锁宇宙观测。** 自服务器记录的永久淘汰真实UTC时刻起满180秒，原玩家账号获得「宇宙观测」只读入口。比赛暂停不影响这一倒计时。
4. **参与四维世界。** 玩家可在中控室围观裁判态势屏幕、使用自己的手机查看只读战局、参加讨论和桌游，或旁听高维提案的现场审议。

维度跃迁提示文案：

```text
【维度跃迁】
你的三维文明已经永久毁灭，但意识仍残留在更高的维度。
请在安全位置摘下全部比赛手环，尽快步行返回中控室。
宇宙观测权限将在永久淘汰满3分钟后开放。
你可以观察宇宙、与其他四维文明交流，并向裁判提出高维干涉建议。
四维世界的信息不得传递给仍然存活的三维文明。
```

### 7.5 中控室与宇宙观测

中控室同时承担赛事指挥和四维活动室的功能。裁判使用笔记本处理母星审核、通讯和现场异常；投影仪、电视或外接显示器展示只读全局态势。推荐采用笔记本扩展屏：笔记本负责裁判操作，大屏幕负责集体观战。永久淘汰玩家也可以在个人手机上打开「宇宙观测」页面。

**四维观察者可以了解完整的当前赛事态势**，包括各文明存亡、母星状态及真实坐标、现役手环配置、光粒与广播资源、历史攻击结果、正在返航的文明及倒计时、正式宇宙事件和已产生的战绩。已发生但尚未面向活人公开的游戏信息，也可供四维世界讨论。

裁判管理按钮、登录凭证、密钥、QQ私人登记照片和尚未发生的随机事件计划保留在裁判工作空间。观战入口是独立只读权限，不开放账号管理、比赛写操作或裁判指令。中控室现场可围观裁判展示的战局数据，正式操作由裁判本人完成。

游戏官网仅将高德六位位置口令作为字符串处理，全场不处理GPS经纬度或行进轨迹。第90分钟起QQ群开启实时位置共享，裁判可在中控室展示QQ群共享地图。四维观察者仍从赛事记录、公开事件及QQ现场展示了解局势。

中控室可准备UNO、骰子、猜词卡、轻量桌游、饮水和零食。观战、闲聊、复盘与桌游均为自由活动，参与者可随时切换。

### 7.6 四维议会与临时宇宙干涉

四维观察者可以随时在中控室讨论宇宙局势、辩论并形成干涉提案；可以口头达成共识，也可以举手投票。提案当面提交给裁判，由裁判根据现场赛事、安全和娱乐效果决定是否批准、调整或暂缓。议会没有固定开会时刻、固定干涉次数或网页投票流程。

裁判使用通用赛事指令控制台执行需要系统支持的干涉，也可以直接口头播报、组织线下活动。指令控制台同时负责常规赛事管理、状态查询和长尾异常处置；四维议会使用其中适合的能力。

适合现场采纳的轻度干涉示例：

| 四维提案 | 效果 | 指令外观示例 |
|---|---|---|
| 宇宙静默 | 全体文明60秒内不能提交目击攻击，比赛时钟继续运行 | `/pause_attack @a 60` |
| 母星余烬 | 向所有活人公布尚存母星总数 | `/reveal @a alive_homeworlds` |
| 高级文明信号 | 公布仍有效且未使用的光粒总数 | `/reveal @a unused_photoids` |
| 黑暗森林回声 | 公布过去10分钟成功目击击毁的总次数 | `/reveal @a kills_last_10min` |
| 高维低语 | 向所有活人发送一句神秘公告 | `/announce @a "你们正在被注视。"` |
| 神秘感应 | 随机选一名存活文明发送不含战术情报的私信 | `/tell @random[alive] "某种高维存在正在关注你。"` |

**四维干涉采用裁判裁量机制。** 纯叙事公告和匿名统计可以灵活使用；短时全场能力变化需要兼顾现场局势；直接决定单个文明生死、改变正式排名等强效果由裁判作为赛事管理和纠错手段掌握。第90—98分钟转场期间，裁判集中监看QQ群共享地图并执行终局资格裁决。

高维公告与官网正式六位坐标广播属于不同事件：高维公告不消耗玩家广播额度，也不生成歌者巡猎。短时攻击静默不冻结120分钟比赛有效时钟；被静默拒绝的攻击请求不累计失配。若同时存在阶段性禁攻和个人错误攻击禁攻，各项限制按各自规则执行。

### 7.7 四维观察者君子协定

全体玩家赛前共同确认：

1. **三维与四维信息隔离。** 永久淘汰后不得向仍存活的玩家通风报信，不得传递手环码、真实母星、位置、战术判断或其他可能影响比赛的消息。
2. **禁止间接传讯。** QQ消息、电话、截图、第三人转告、现场暗号、表情提示、故意提供假消息等均属于信息传递。
3. **死者之间自由交流。** 四维观察者可讨论从观战页面和个人经历获得的全部赛事情报，分享外交故事与推理。
4. **三维现场退出。** 观察者不在比赛区域继续侦察、跟踪或干扰活人；需要处理个人事务或安全情况时可以正常联系工作人员。
5. **干涉经裁判实施。** 观察者可以建议和说服裁判，实际赛事操作由具备管理权限的裁判完成。
6. **共同维护约定。** 违约者失去后续四维观战及提案参与资格；影响正式战局的事项由总裁判根据违规处理规则裁决并记录。

观战权限建立在共同遵守约定的基础上。赛前向所有人明确四维观察者可见的赛事信息范围，让活人与死者都了解各自承担的游戏角色。

### 7.8 文明故事与赛后复盘

中控室设置自愿的「宇宙档案馆」：每位死者可以讲述或记录文明墓志铭、一次外交、一次误判、背叛或求生经历。可以现场聊天记录、写纸条或由主持人收集，不设置专用积分和复杂网页功能。

比赛结束后安排约10—15分钟全员战报、复盘与颁奖。公布冠军、去重战绩、重要的广播与光粒事件，邀请活人与四维观察者共同讲述故事。「宇宙猎手」「最佳文明故事」「最佳文明遗言」等趣味荣誉独立于正式生存排名。

空清理包含空坐标及已毁母星，公告不进一步公布其历史性质。65分钟全域末日公告按第5章模板执行，不提前公示其他文明的秘密母星坐标。

### 8.4 一键复制与消息送达

母星登记、重生和异常申报页提供「复制消息」，始终采用服务器已保存的本人数据生成文案。玩家必须自行在QQ粘贴并附照片，复制并不表示已发送。

裁判消息队列区分`待发送/已复制/已发送/异常待处理`，分开记录操作者与时间。正常击毁与直接出局的秘密通知优先处理；QQ送达延迟不影响服务器已经结算的飞船状态、出局状态或15分钟重生截止。允许合并播报空坐标歌者事件，但真实母星毁灭与光粒命中分别公开。

## 9. 玩家网页功能与最小暴露

玩家网页根据服务器阶段、本人航次与攻击禁攻状态展示合法入口。前端隐藏无权操作，服务端必须重新核验。

| 当前状态 | 网页主要显示 |
|---|---|
| 报到/母星未核验 | 文明昵称、六位母星提交与版本、QQ复制模板、审核进度 |
| 母星已核验、未离巢 | 离巢50米确认、核对七色手环材料包 |
| 已离巢、T0未到 | 「待发码就绪」、T0倒计时，不能提前领取手环码 |
| T0已到、首航码已领取 | 双臂颜色配置图、3—4条佩戴提示、「穿戴就绪」，没有攻防入口 |
| 已穿戴就绪、T1未到 | T1统一开赛倒计时 |
| 第一阶段正常出航、母星尚存 | 两侧图形化目击输入、本人去重数、广播、光粒及秘密情报 |
| 第一阶段正常出航、母星已毁 | 最后一命、图形化目击输入、剩余合法宇宙行动 |
| 被击毁返航 | 摘掉全部手环、15分钟倒计时、母星拍照、QQ复制消息 |
| 准备/已领重生码 | 离巢提示、全新双臂配色图、佩戴确认与完成出航 |
| 目击禁攻但仍正常出航 | 倒计时与失配次数；仍可被目击击毁，其他合法行动不受影响 |
| 永久淘汰后未满3分钟 | 摘环与返回中控室指引、本人战绩、宇宙观测解锁倒计时 |
| 永久淘汰满3分钟 | 只读宇宙观测入口、全局战局、历史事件与本人赛后档案；没有裁判操作权限 |
| 第二阶段正常出航 | 最后一命、手环目击、去重数与终局地图 |
| 90:00—98:00转场 | QQ实时位置共享、终局地图与倒计时；隐藏目击入口 |
| 98:00终局资格核验暂停 | 位置共享提醒、当前存活状态、终局地图与核验中提示；目击关闭 |
| 核验完成后的终局幸存者 | 继续当前佩戴、图形化目击、位置共享提醒与有效比赛倒计时 |
| 完赛（120:00或自动提前完赛） | 正式名次、去重战绩、宇宙战报 |

**图形化目击输入：** 两个无左右标签的手臂栏位「一侧」「另一侧」，各点选颜色。各颜色本次只能在一侧出现，满足`2+1`、`2+2`或`3+1`才启用确认。服务器统一将左右交换归一化；同臂排列无先后顺序。输入只能使用七种颜色，不能输入外貌、昵称、文明编号、额外数字或图案。颜色按钮同时显示中文色名，并有足够大小供触控；图形示意与本人真实手环颜色应经样品校准。

未命中时本人看到「本次目击未产生击毁」、累计失配次数及适用的禁攻截止时间；合法攻击命中后展示目标身份和母星口令。相同请求ID网络重试返回同一结算结果。

## 10. 裁判分工与中控室

### 10.1 裁判岗位

| 岗位 | 核心工作 |
|---|---|
| 1号：通讯与母星裁判 | QQ母星口令与照片核对、官网待审核记录批准、重生照片抽查、失联与淘汰私聊 |
| 2号：宇宙事件裁判 | 广播、歌者、光粒和技术爆炸公告与私聊、到期事件队列、网络异常 |
| 3号：总裁判/巡查 | 七环颜色可辨性、佩戴合法性与安全巡查、错误攻击争议、T0/T1、设备异常换码、终局人工淘汰和排名 |

15:05—15:15按网站的待审核口令和提交版本核对QQ照片，点击通过或驳回；第90—98分钟全体裁判监看QQ群位置共享；98:00服务器暂停有效时钟，裁判核实名单并由总裁判完成资格淘汰、开启终局；最后狩猎期间持续处置离圈及共享中断。错误攻击直接出局由服务器结算；总裁判根据可核实的技术故障执行记录在案的纠错。

### 10.2 中控室安排

中控室设置裁判笔记本、集体观战屏幕和自由活动区域。使用笔记本扩展屏展示只读宇宙态势，裁判管理界面和指令操作保留在工作屏幕。具备条件时安排一名志愿者维护投影、桌游及回到中控室的观察者秩序。

四维观察者需要提出高维干涉时，集中到裁判工作台附近讨论，裁判可选择现场旁听、听取代表陈述或请大家先自行商议。裁判优先处理正式比赛、紧急事件与玩家申诉。

### 10.3 通用裁判指令控制台

裁判GUI提供母星审核、公告待办、T0/T1、时钟暂停、终局人工淘汰与开战、调度健康及事件待办等常用操作；指令控制台提供状态查询、精细状态修复、异常事件复核、临时能力控制、统计公布、通知发送和其他长尾操作。

指令采用类似Minecraft的`/command target arguments`外观。裁判可以查询文明及事件历史、调整玩家状态与资源、补发或撤销事件、为比赛设置临时效果、处理复杂异常。高影响操作先展示影响范围和确认信息，所有执行记录操作者、原因和状态变化。详细功能和实现接口见配套技术方案。

控制台由裁判使用。四维观察者可以提出任意有趣的想法，裁判从可用管理能力中选择合适方式实现。

## 11. 安全与公平

- 全程正常步行；禁止奔跑追逐、身体接触、推搡、堵路、拦截、围困、拉扯手环或他人衣物。保持安全距离。
- 仅观察目标两臂现役手环的颜色分组；不得拉住对手、要求对方停步展示或抬起手臂，也不得擅自接触他人的腕部。
- 正常出航者应露出比赛手环，不用袖口、背包、手掌等物品刻意遮挡；允许自然摆臂、正常转向与绕行。手环可以在同臂滑动，顺序变化不影响编码。
- 被击毁、返航、准备、直接出局、永久淘汰时均应在安全位置摘掉全部比赛手环。正常出航者不得主动摘环、藏环或自行换码来逃避攻击。
- 不得增加同色手环、替换供应商型号、使用额外标识、反面图案、粗细差异或衣着信息作为目击编码。
- T0前不得领取本场首航码；T0至T1之间不观察他人正在佩戴的准备码，T1后必须重新亲眼目击才能攻击。
- 禁止拍照、录像、截图放大他人手环，禁止传播当前有效手环码、使用猜码脚本、账号代登、约定互刷战绩；六位母星坐标可依法交易与编造。
- 禁止进入教学楼和宿舍内部、机动车道、施工区、危险水边、围栏外及校方禁止区域。
- 禁止蹲守母星，禁止尾随返航、离巢或换码者直至其出航后立即袭击。
- 第三阶段按既定规则保持QQ群共享位置；不得虚拟定位、代持手机或越界攻防。赛前说明范围并征得同意。
- 永久淘汰者及时摘环并返回中控室，遵守四维君子协定，不向活人传递赛事情报。
- 观战屏幕展示赛事状态；裁判管理账号、登录凭证、私人登记照片及裁判操作界面由工作人员管理。
- 大面积网络故障或人身安全事件由总裁判统一暂停比赛有效时钟，恢复后按原剩余时间继续。

## 12. 裁判应急处理

**手环遗失、损坏、颜色混淆或码配错误：** 玩家应在安全位置停止主动操作并报告裁判。若是本人仍持有的相同颜色同规格手环损坏，可经裁判核对使用同色同款备用环，保持原码不变。若当前配置已泄露或不可恢复，需要注销并换发新码时，裁判统一暂停比赛、事务化退役旧码、签发本场尚未使用的码，核对新佩戴并恢复；异常作废码永久占用容量，不得复用。替换装备时必须保持两臂颜色集合编码规则。

**网页或网络故障：** 全场性访问故障由总裁判依据恢复后的权威时钟与审计记录决定暂停及纠错；只有暂停指令在服务器成功提交时比赛时钟才开始冻结。单个裁判设备熄屏或断网不影响已排定事件的服务器调度。若转为人工判定，须先执行可验证的全场暂停并统一宣布切换，裁判以两侧手环颜色集合及提交顺序核对唯一发码簿，正确击毁与错误攻击处罚均按赛事规则办理，恢复后由裁判统一补录事务与日志。

**QQ通知延迟：** 有效击毁与15分钟重生截止按服务器权威比赛时钟生效；裁判优先私聊通知。联系不到时只提示查看本人官网，不公开秘密母星或现役手环码。玩家应在比赛中主动关注网页个人状态，QQ送达与网页读取均不构成时钟起算条件。

**错误攻击申诉：** 裁判核对请求是否正式受理、是否命中本场已退役旧码或本人码、是否为网络重试、比赛阶段或个人禁攻拒绝，以及随机抽签是否重复执行。确认系统误判时，裁判依据日志恢复正确状态并记录处理。

**码源紧张：** 裁判后台展示剩余可用码数，降至20枚、10枚时私下提醒总裁判核查是否存在异常消耗，不改变玩家重生资格。若350枚全部发行、合法新航次仍需要新码，必须暂停比赛并公开说明已发生不可继续发码的技术与规则冲突；禁止暗中复用旧码或按玩家身份差别限制重生。是否中止赛事实验由总裁判统一说明并记录。

**终局共享位置异常：** QQ共享地图无法正常显示时，总裁判暂停比赛有效时钟，裁判核实共享与入圈情况后人工完成资格淘汰，并宣布恢复比赛。**随机事件异常：** 服务端调度故障由总裁判查看事件日志、安排补结算并记录处理。

**复杂个案与长尾修复：** 裁判通过指令控制台查询玩家、航次、攻击及事件记录，预览并执行相应纠错，必要时统一暂停赛事。恢复合法状态后重新检查当前码、名次及通知是否一致。

**临时四维事件：** 裁判根据现场提案实施公告、统计公开或短时能力变化，记录事件来源、执行时刻和效果范围。正式赛事核验及安全处置优先。

## 15. 赛事系统与裁判操作边界

### 15.1 官网与云端系统

官网采用Cloudflare Pages静态前端和Pages Functions同源API，比赛的权威状态集中在单场SQLite-backed Durable Object中；Cloudflare Alarms根据持久化计划事件主动执行服务端结算。阿里云继续负责正式子域名的权威DNS，通过CNAME接入Pages。所有玩家与裁判只访问公布的正式HTTPS子域名。

T0首航开放、T1统一开赛、15分钟重生超时、歌者清理、秘密技术爆炸、65分钟宇宙末日、90分钟转场、98分钟终局资格截止与自动暂停、120分钟完赛均依服务器比赛时钟。裁判在98分钟核验暂停期间提交资格淘汰名单并完成终局开战；比赛亦可因存活文明不超过1个而自动完赛。已安排的Alarms负责服务端定时事件；裁判操作及QQ现场核验由人工完成。

所有正式操作以服务器确认成功为准；页面倒计时仅用于展示，网络重试必须复用同一操作请求ID。全场暂停需要总裁判通过已认证的管理接口实际提交，成功后冻结比赛有效时间，恢复时继续剩余时长。个人错误攻击禁攻和永久淘汰后180秒四维观战等待均按真实UTC计算。

### 15.2 裁判人工职责

服务器处理线上行动资格、第二次失配概率判罚、击毁、重生期限、母星毁灭、阶段转换、广播额度、光粒、观战授权与正式排名。裁判负责母星水印照片核验、QQ公告及私聊、终局QQ群位置共享人工监看、手动淘汰、终局开战、安全巡查和争议裁决。QQ群消息以裁判实际发送为准。

第90—98分钟裁判持续监看幸存者的QQ共享位置，以98:00为资格截止；此时服务器暂停有效时钟，裁判在后台选择应淘汰文明，由总裁判一次性确认资格裁决并结束核验暂停。最后狩猎期间由裁判继续监看、手动淘汰离圈或中断共享者。官网记录淘汰原因和裁判操作时间，位置数据留在QQ共享会话中。

### 15.3 系统异常与公平性

服务器不能访问时，个人手机显示的状态不构成最新权威信息。全场性网站故障或现场安全事故由总裁判统一公告并按已持久化时钟操作暂停。任何延期结算、判罚纠错、码源耗尽与终局争议都应保留日志、判定依据及人工通知记录；不得复用已发行手环码、跳过错误攻击概率处罚或暗中改变排名。
