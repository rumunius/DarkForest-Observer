# 前端视觉补充修正（2026-11-04）

依据用户本次前端美化要求，本补充覆盖《网站前端设计系统》§2.2、§2.3、§7.1、§10中与本次视觉效果冲突的限制。它承接同日的《前端交互补充修正》，不改变玩法、服务器允许动作、颜色身份、处罚、时间或观战授权。两份核心策划与技术文档保持原文。

## 手部与手环

使用内联SVG绘制手形。按用户要求，手掌改编自Tabler Icons的现成SVG，采用自然曲线、圆弧指尖及少量掌部线条，来源和完整MIT许可见[手部SVG参考与许可](手部SVG参考与许可.md)。手环在手腕下方沿前臂排列，使用轻微弧形边缘与侧扣线表达环绕关系，避免宽矩形悬浮在手掌之上。手环正面始终读取统一配置的原色，不增加材质、编号或新的编码维度；每条手环仍有独立至少44px高的操作区域。点选、移除、自动溢出、四条上限、两臂交换等价与二次确认沿用既有规则；拖放已按用户后续要求完全取消，见[前端交互补充修正](前端交互补充修正_2026-11-04.md)第8项。

按用户追加要求，非拇指的四指长度依次为中指、食指、无名指、小指，无名指略短于食指。竖屏目击页采用紧凑的双臂与色盘布局，将处罚说明及确认攻击区域固定在底部导航上方，适配安全区；形成合法配置后，攻击按钮无需滚动即可完整显示。开发预览可在地址追加 `tools=hidden` 隐藏开发工具栏，以核对实际玩家页面的视口。

## 强调色

黑白仍占主体。击毁、永久淘汰及高风险错误后果使用少量柔和红色；目击提交、核对与受限提示使用少量琥珀黄色。强调落在状态文字、图标、细边线和关键时间，不铺高饱和背景，不把业务手环色当作界面语义色。

## 特殊状态气氛

| 服务器已有状态                   | 视觉表达                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------- |
| 被击毁后，返航、准备或新配置阶段 | 明显的暗红四角光晕、稀疏漂浮微粒、一次性边缘故障及色散；关键标题红色，重生剩余时间黄色 |
| 正常出航且母星已毁               | 暗红四角光晕缓慢呼吸，强度低于击毁状态；最后一命提示黄色                               |
| 个人禁止目击                     | 清晰的琥珀四角光晕和断续轨道投影；仍显示可被击毁及其他合法行动的原有说明               |
| 转场、资格核验                   | 淡琥珀气氛，核验暂停时冻结装饰动画                                                     |
| 最后狩猎                         | 暗红棕色四角光晕、稀疏微粒、低频边缘故障及色散，与局部黄色提示                         |
| 永久淘汰但尚未获得观战权限       | 暗红四角光晕、一次性边缘故障及色散和淘汰提示，不提前显示四维观战效果                   |
| 服务器确认观战资格               | 视口中央的灰白超立方体线框，以16顶点、32条边的四维旋转投影缓慢变化                     |

本次明确允许用于装饰层的径向渐变、明显可见的角落光晕、短暂通道错位、粒子及线框投影，替代旧设计系统对这些效果的全面禁止。按用户最新要求，发光集中在视口四角，向内平滑渐隐，呈现类似暗角的包围感；取消贯穿左右的竖向光幕、发亮边框及侧边细线。竖屏下四角仍清晰可见，两侧中段与中央阅读区保持通透。黑白仍占页面主体，不使用高饱和霓虹或整屏染色。普通状态、登录、裁判和赛后页面不添加这些玩家状态气氛。特效由已有状态派生，不自行推断淘汰或授予观战权限；禁攻到期按UTC时基取消相应视觉限制，不改变服务端授权。

### 故障与色散的触发条件

- 进入被击毁后的返航、准备、领码状态组，或进入永久淘汰但尚未开放观战的状态时，播放一次约900ms的边缘断带与轻微通道错位；返航→准备→领码仍属于同一状态组，不重复播放，组内切换页面或轮询也不重播。重新加载页面会按当时状态重新创建效果。
- 玩家仍在出航、比赛进入最后狩猎，且不处于转场或资格核验时，每12秒播放一次约200ms的边缘断带与色散。进入狩猎后先保持安静，接近第12秒才出现第一次干扰。
- 最后一命仅保留四角光晕和缓慢呼吸，个人禁攻仅保留琥珀四角光晕与断续轨道，转场或核验仅保留淡琥珀气氛；这些状态不单独触发故障。重叠状态沿用既有优先级：转场或核验优先于狩猎，狩猎优先于最后一命及个人禁攻。因此，狩猎中的禁攻到期不会取消狩猎特效。
- 四维投影仅在服务器确认观战资格后显示，不叠加击毁或狩猎故障。投影容器按视口中心定位，每次绘制还会校正透视投影包围盒的中心，避免旋转过程中再次偏向一边。
- 比赛暂停、页面隐藏、系统或账号开启减少动态效果时停止动态干扰。被中断的一次性击毁演出直接结束，恢复后不补播；狩猎干扰恢复后重新等待一个周期。

## 可读性、动效与降级

按用户追加要求，装饰层固定在界面最上方，覆盖面板、按钮、底部导航及确认弹窗，形成统一的后处理观感。使用不自动聚焦的手动Popover进入浏览器顶层，确认弹窗打开后重新置顶；不支持Popover的旧浏览器退化为高层级固定覆盖。整个层、全部子元素及透明背景均为 `pointer-events: none`，并对读屏隐藏，不接收焦点，不拦截触摸、点击或滚动。

光晕在四角清晰可见，中央大部分区域保持透明；微粒避开中央阅读区，故障断带仅分布在左右最外侧15%以内。正文、手环及按钮自身不应用滤镜、模糊、位移或闪烁，其几何与命中区域不变；覆盖层的微弱色彩可以经过控件表面。按用户追加要求，居中四维线框缩小约两成，以20%不透明度穿过界面。所有故障均不闪白、不震屏、不延迟结果文字。

手环转移动画从当前可见位置续接快速输入，窗口尺寸变化、失焦或标签页隐藏时直接落位。确认弹窗使用轻微进入动效，普通按钮与导航保留短促反馈。系统减少动态效果或账号相应偏好生效时取消空间动画；页面隐藏、比赛暂停时停止非必要环境动画，恢复后不补播。四维投影仅在需要时创建，并限制绘制频率；不引入动画库、位图或远程视觉资源。
